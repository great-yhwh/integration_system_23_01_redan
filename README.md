# Интеграция систем

Система синхронизации данных между CMS API и Report API 
с использованием Apache Camel как интеграционной платформы и 
PostgreSQL для хранения исторических данных.

| Компонент       | Технология           | Назначение                   |
|-----------------|----------------------|------------------------------|
| Платформа       | **Spring Boot 3.3**  | Основа приложения            |
| Интеграция      | **Apache Camel 4.8** | Маршрутизация и ETL          |
| База данных     | **MongoDB**          | Хранение исторических данных |
| Контейнеризация | **Docker**           | Изоляция                     |
| Сборка          | **Maven**            | Управление зависимостями     |
| Язык            | **Java 17+**         |                              |

## Быстрый старт

### Клонирование репозитория

```bash
git clone https://github.com/great-yhwh/integration_system_23_01_redan.git

```

```bash
cp .env.example .env
```

```bash
docker compose up -d
```

```bash
./mvnw spring-boot:run
```

### Запуск тестов

```bash
./mvnw test
```
## Потоки данных

### Поток А: CMS → MongoDB (Синхронизация)
1. Camel вызывает CMS API с пагинацией.
2. Полученные записи сравниваются с данными в MongoDB.
3. Новые записи — вставляются, а изменённые — обновляются.
4. Записи, отсутствующие в CMS, помечаются isDeleted = true. 

### Поток Б: MongoDB → CSV → Report API (Отчёт)
1. Из MongoDB извлекаются все записи (включая удалённые).
2. Данные преобразуются в CSV-файл (UTF-8, разделитель «;»).
3. Файл отправляется в Report API через HTTP POST.
